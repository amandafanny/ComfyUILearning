**Canny Edge 用来从参考图中提取轮廓，输出一张黑底白线的边缘图。** 它寻找相邻像素变化明显的位置。比如一张汽车照片，车顶、车窗、轮胎的边界都可能变成白线，车身上颜色均匀的区域则呈黑色。把边缘图交给 Canny ControlNet，就可以让新图参考原图的轮廓和构图。[docs.opencv.org](https://docs.opencv.org/4.x/da/d22/tutorial_py_canny.html?utm_source=chatgpt.com)

以下按 `comfyui_controlnet_aux` 插件里的 **`Canny Edge`** 说明。它有 **1 个输入、1 个输出、3 个可调参数**。[huggingface.co](https://huggingface.co/Ly820359009/comfyui_controlnet_aux/blob/b36082140333bfa45f70872ad205ea74d3b3e64e/node_wrappers/canny.py?utm_source=chatgpt.com)

### 一、输入接口

| 接口    | 类型    | 接什么                                                                                                                                                                                                                                                |
| ------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `image` | `IMAGE` | 接 `Load Image` 输出的原图。选择你想保留轮廓的照片、插画或上一节点生成的图片。[huggingface.co](https://huggingface.co/Ly820359009/comfyui_controlnet_aux/blob/b36082140333bfa45f70872ad205ea74d3b3e64e/node_wrappers/canny.py?utm_source=chatgpt.com) |

### 二、输出接口

| 接口    | 输出内容                                                                                           | 接到哪里                                                                                                                                                                                                       |
| ------- | -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `IMAGE` | **黑底白线的边缘图**。白线表示检测到的边界。和前面讲的 Depth Anything 不同，这里的黑白不表示远近。 | 接 `Preview Image` 检查提取了哪些线。要用它引导生成，就接 `Apply ControlNet.image`，并加载与基础模型匹配的 **Canny ControlNet**。[ComfyUI](https://docs.comfy.org/built-in-nodes/Canny?utm_source=chatgpt.com) |

### 三、节点自身的 3 个可调参数

| 参数                    | 默认值 |                      范围 | 控制什么                                                                                                                                           |
| ----------------------- | -----: | ------------------------: | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `low_threshold` 低阈值  |  `100` |             `0–255`，整数 | **微弱的线能否接续到强边缘上。** 调低它，浅纹理、细线更容易保留；调高它，可以减少杂线。                                                            |
| `high_threshold` 高阈值 |  `200` |             `0–255`，整数 | **多明显的变化才足以确认为强边缘。** 调低它，更多轮廓有机会被识别；调高它，主要留下对比明显的边缘。                                                |
| `resolution` 处理分辨率 |  `512` | `64–16384`，界面步进 `64` | **先把原图按比例缩放到指定短边，再检测边缘。** 例如 `1200 × 800` 的图设为 `512`，就在 `768 × 512` 上提线。因此，改分辨率也可能改变能检测到的细节。 |

两个阈值比较的是**局部变化强度**。用默认的 `100 / 200` 举例：强度为 `230` 的候选边缘直接保留；强度为 `150` 的候选边缘，只有能连到强边缘时才保留；强度为 `60` 的则丢弃。这样既能沿着车顶接出一条完整曲线，又能过滤掉孤立的浅纹理。[docs.opencv.org](https://docs.opencv.org/4.x/da/d22/tutorial_py_canny.html?utm_source=chatgpt.com)

**实际调参时先看预览。** 如果车身反光和路面纹理形成了太多杂线，先把 `low_threshold` 从 `100` 提到 `130` 试一次。如果连车门这样的主要轮廓都没检测出来，先把 `high_threshold` 从 `200` 降到 `160`。每次只改一个值，更容易看出哪类线受到了影响。[docs.opencv.org](https://docs.opencv.org/4.x/da/d22/tutorial_py_canny.html?utm_source=chatgpt.com)

如果你界面上**只有两个小数参数，默认是 `0.4 / 0.8`**，你用的是 ComfyUI **内置 `Canny`**。它同样使用低、高阈值，但范围是 `0.01–0.99`，没有独立的 `resolution` 设置，应使用该节点自己的数值范围。[ComfyUI](https://docs.comfy.org/built-in-nodes/Canny?utm_source=chatgpt.com)
